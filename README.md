# Forge the Day privacy policy

This repository hosts the [published privacy policy](https://dami777-code.github.io/forge-the-day-privacy/) for Forge the Day's private beta. The policy applies to the version and configuration named on that page.

The site is deployed from `index.html` using GitHub Pages. For the product and engineering overview, see the [Forge the Day case study](https://github.com/Dami777-code/forge-the-day-case-study).
